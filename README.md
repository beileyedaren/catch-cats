# 🐱 找小猫 (Catch the Cats)

一个纯 HTML 单文件网页小游戏：上传一张图片，小猫会藏进图里，限时全部找出即可过关！

## 🎮 玩法

1. 打开 `index.html`，上传一张图片（建议用细节丰富的照片，如房间、公园、桌面）
2. 小猫会随机藏在图片中，点击找出它们
3. **第 1 关**：3 只小猫，藏得比较显眼，容易找到
4. 之后每关小猫数量 +1，并且：
   - 🐱 体型越来越小
   - 👻 越来越透明
   - 🔄 第 2 关起随机旋转角度
   - 🌫️ 第 4 关起使用混合模式，融入背景
   - ⏰ 限时越来越短（最低 20 秒）

## 🏆 计分规则

- 找到一只小猫：**+100 分**（带金币飘字 + 星星粒子特效 ✨）
- 过关奖励：**剩余秒数 × 10 分**，手速越快积分越高
- 超时未找齐：**闯关失败**，可重新挑战

## 🚀 运行方式

纯静态单文件，无需任何依赖：

- 直接双击打开 `index.html`，或
- 用任意静态服务器运行，例如：`npx serve .`

## 🛠️ 技术

- 原生 HTML / CSS / JavaScript，零依赖
- Canvas 五彩纸屑过关特效
- CSS 动画实现得分飘字、粒子、震动反馈
